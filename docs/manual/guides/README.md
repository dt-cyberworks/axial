# Guides

**Who this is for:** operators and admins who have a job to do and want the steps.
**After this page you can:** pick the guide for the job in front of you.

Each guide is one job from start to finish. For the meaning of a screen or a field, use the [screen reference](../reference/README.md); for the ideas behind them, [Concepts](../concepts.md).

| Job | Guide |
|---|---|
| Say what you are allowed to test, and when | [Define an engagement and its scope](define-an-engagement.md) |
| Record that you are permitted, and switch the engagement on | [Authorize and activate](authorize-and-activate.md) |
| Decide which kinds of tools may run | [Control which tools run](control-which-tools-run.md) |
| Run a scan, watch it, stop it | [Start and watch a scan](run-a-scan.md) |
| Make a scan wider, deeper or gentler | [Tune a scan](tune-a-scan.md) |
| Answer a request that is waiting for your decision | [Approve or deny a tool call](approve-or-deny-a-tool-call.md) |
| Decide what to do with each finding | [Triage findings](triage-findings.md) |
| See what changed since the last scan | [Compare runs](compare-runs.md) |
| Produce the document for the customer | [Reports](reports.md) |
| Add people, set up their sign-in, recover access | [Users and two-factor authentication](users-and-mfa.md) |
| Let the AI agent and the finding explanations work | [Configure the AI provider](configure-the-llm.md) |

If something is blocked or failed, go to [Troubleshooting](../troubleshooting.md).
